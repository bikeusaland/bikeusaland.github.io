always-on-agent: Privacy policy

Last updated: November 8, 2026

Who uses this app

always-on-agent is a personal tool that runs only on its owner's Mac. Its only user is the owner, who authorizes it to access their own Google account. It is not offered to anyone else.

Google data accessed

The app requests the Gmail scopes gmail.modify and gmail.compose. It uses them only to do what the owner asks: search and read mail, create drafts, send mail (after the owner approves, unless every recipient is on the owner's own allowlist), apply labels, archive, mark read or unread, and move mail to Trash (only after the owner approves). It cannot permanently delete mail.

How data is stored and processed

  • The OAuth refresh token is stored in the owner's own password vault (1Password or macOS Keychain) on the owner's Mac. Access tokens are kept in memory only.
  • Mail content is processed on the owner's Mac by a local language model. When the owner chooses to escalate a request, the relevant content is sent to Anthropic's Claude API to answer that request.
  • Mail content is not sold, used for advertising, or shared with anyone else, and is not used to train AI models.

Google API Services User Data Policy

always-on-agent's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.
